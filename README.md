# Hệ Thống Phân Tích Dữ Liệu Seller Bất Động Sản

Môn học Cấu trúc dữ liệu và Giải thuật.

## Chức năng

* Đọc dữ liệu nhà đất từ file CSV (melb_data.csv).
* Sắp xếp danh sách nhà theo **Năm xây dựng** (cũ đến mới) dùng **Merge Sort**.
* Sắp xếp danh sách nhà theo **Mã bưu điện** (Postcode) dùng **Radix Sort**.
* Tìm người bán (Seller) bán được nhiều nhà nhất.
* Xuất file kết quả sau khi sắp xếp.

## Ngôn ngữ sử dụng

* Ngôn ngữ: C
* Kỹ thuật: Struct, Mảng, File I/O, Merge Sort, Radix Sort.
⇒ Chương trình nhằm mục đích ứng dụng thuật toán sắp xếp merge sort, radix sort, struct bằng ngôn ngữ C để xử lí dữ liệu lớn từ CSV.
